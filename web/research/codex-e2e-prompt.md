# Задача для Codex: мультиплеерный тест и нагрузка

Пишешь только `web/research/e2e_mp.js` и `web/research/E2E.md`. Код игры не трогай: его параллельно правят другие.

Прочитай `web/server.js` (события сокета: `join`, `pick`, `ready`, `addBot`, `mode`, `input`, `buy`, `cast`, `pickup`, `forge` и что там ещё есть) и `web/research/codex-core2-prompt.md` (что скоро добавится: `j` в input, `code`, турели, гранаты).

## Что нужно

`node web/research/e2e_mp.js [url] [--rooms N]` (по умолчанию `http://localhost:3000`, 1 комната), клиенты на `socket.io-client` (он уже есть в `web/node_modules`, иначе добавь в devDependencies).

Сценарии, каждый печатает PASS / FAIL / SKIP с причиной:

1. **2v2**: 4 живых клиента в одной комнате, выбор персонажей, ready, фаза `buy` → `playing`, каждый что-то покупает, стреляет друг в друга (`input` с `ax/ay` на врага), кто-то умирает, раунд кончается, счёт меняется, деньги начислены по `ECON`
2. **dm**: 3 клиента, убийство, возрождение через ~3 с, счёт киллов
3. **Бомба**: у команды 0 есть носитель, закладка (если в сервере уже есть событие `code`, через него, иначе держать G), взрыв или дефьюз меняют итог раунда
4. **Ларёк**: покупка `molotov` только в круге ларька, вне круга отказ
5. **Бабки**: выстрел в бабку, она отвечает стрелку
6. **Новое из ядра v2**, если сервер это уже поддерживает (проверяй по snapshot, иначе SKIP): прыжок даёт `z > 0`, турель, кофе
7. **Нагрузка** `--rooms N`: N комнат по 4 клиента, 60 с боя ботами и живыми, печатает интервал между snapshot (среднее, p95, p99, должно быть около 33 мс), задержку `input → изменение позиции`, число отвалившихся сокетов

Плюс `--json` для машинного вывода. Таймауты на каждый сценарий, тест не виснет.

`E2E.md`: как запускать против локального сервера и против ноута Володи по IP, что значит каждый FAIL.
