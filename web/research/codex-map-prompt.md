# Задача для Codex: карта «Спальник»

Сначала прочитай `web/research/CONTRACT.md`. Формат карты и границы файлов оттуда главнее этого текста.
Пишешь только `web/public/maps/rayon.json`, `web/public/map3d.js`, `web/public/map2d.js`, `web/research/check_map.js`. Остальное не трогай.

## Что за карта

Браузерный шутер 2 на 2 в духе CS, бойцы брейнрот-персонажи. Карта это московский спальный район, двор, который узнаёт любой студент.
Стиль лоу-поли, плоские цвета, как Totally Accurate Battle Simulator. Без фотореализма и без внешних моделей и картинок.

Раскладка (поле 1600 на 900, слева направо):

- **Спаун команды 0** у магазина «Шестёрочка» (пародия, настоящих логотипов нет), западный край.
- **Спаун команды 1** на перекрёстке со светофором и зеброй, восточный край.
- **Мид** через арку в длинной панельке по центру. Арка это узкий проход шириной 90–110 px в `solid`-стене.
- **Точка A** у гаражей-ракушек (северо-восток): «Лада» на кирпичах как `low`-укрытие, рядом заниженная тонированная «Приора» как `solid`.
- **Точка B** на детской площадке (юг): горка, качели, песочница. Горка и песочница `low`, через них простреливается.
- **Ларёк «Красное и Бухое»** (пародия) между мидом и B: `shops` с `items: ["molotov"]`, там во время боя продают зажигалки.
- **Лавка у подъезда** с двумя бабками (`npcs`, `kind: babka`), на линии от спауна 0 к миду.
- `audio` вокруг «Лады», `track: "lada"`.
- Декор: тополя, фонари, мусорки, граффити на гаражах, ржавый турник.

Правила баланса раскладки: от каждого спауна до каждой точки примерно одинаково (разница не больше 15%), к каждой точке минимум два входа, нет прямой линии через всю карту без укрытия, спауны не простреливаются друг из друга.
В отчёт: расстояния спаун → A, спаун → B для обеих команд (прямая через проходы, можно грубо по сетке).

## `map3d.js`: ES-модуль на Three.js 0.180

```js
import * as THREE from '/vendor/three.module.js';
export async function buildMap(scene, map) { /* возвращает { group, dispose } */ }
```

- Карта приходит готовым объектом из JSON. Перевод координат из контракта.
- Панельки: коробка плюс текстура окон, нарисованная кодом на `CanvasTexture` (сетка окон, часть горит жёлтым, балконы, кондиционеры). Одна текстура на все панельки.
- Оптимизация обязательна: одинаковые `kind` через `InstancedMesh` или слияние геометрий, **не больше 60 draw calls** на всю карту, `MeshLambertMaterial` или `MeshStandardMaterial` с плоскими цветами, тени только у `solid` и игроков.
- Вывески «Шестёрочка» и «Красное и Бухое» текстом на `CanvasTexture`.
- `dispose()` чистит геометрии, материалы и текстуры.

## `map2d.js`: запасная 2D-картинка

```js
(function (root) { function drawMap(ctx, map) { /* вид сверху */ } root.MAP2D = { drawMap }; })(this);
```

Обычный скрипт без модулей. `solid` тёмные блоки с подписью `kind`, `low` светлее, точки A/B кругами с буквой, ларёк значком.
