# Контракт: карта, оружие, сущности

Общий для трёх задач Codex (карта, оружие, сервер). Кто меняет этот файл, тот сообщает остальным.
Мир плоский: сервер считает всё в 2D, пиксели, поле `W=1600`, `H=900`. 3D это только картинка.
Перевод в 3D: 1 юнит = 40 px, `X = x/40 - 20`, `Z = y/40 - 11.25`, `Y` вверх.

## Кто какие файлы трогает

| Задача | Пишет | Только читает |
|---|---|---|
| Карта | `public/maps/rayon.json`, `public/map3d.js`, `public/map2d.js` | всё остальное |
| Оружие | `public/weapons.js`, `forge.js`, `public/parts3d.js`, `research/balance.md` | всё остальное |
| Сервер | `server.js`, `public/client.js`, `public/index.html`, `lib/*` | всё остальное |

Каждая задача ещё пишет свой скрипт проверки `research/check_<задача>.js`. Чужой файл не править. Нужна правка в чужом, пиши её в конец своего отчёта.

## Формат карты `public/maps/<id>.json`

```json
{
  "id": "rayon", "name": "Спальник", "W": 1600, "H": 900,
  "solid": [{ "id": "p1", "kind": "panelka", "x": 0, "y": 0, "w": 400, "h": 120, "height": 9 }],
  "low":   [{ "id": "b1", "kind": "bench",   "x": 0, "y": 0, "w": 60,  "h": 20,  "height": 0.6 }],
  "decor": [{ "kind": "poplar", "x": 0, "y": 0 }],
  "spawns": { "0": [[100, 450], [100, 520]], "1": [[1500, 450], [1500, 380]] },
  "sites":  { "A": { "x": 0, "y": 0, "r": 110 }, "B": { "x": 0, "y": 0, "r": 110 } },
  "shops":  [{ "id": "kb", "x": 0, "y": 0, "r": 70, "items": ["molotov"] }],
  "npcs":   [{ "kind": "babka", "x": 0, "y": 0 }],
  "audio":  [{ "x": 0, "y": 0, "r": 260, "track": "lada" }]
}
```

- Все прямоугольники выровнены по осям (`x, y` = левый верхний угол), без поворота. Так коллизия стоит копейки.
- `solid` блокирует движение и пули: панельки, гаражи, киоск, машины, забор.
- `low` блокирует движение, но **не пули**: лавка, песочница, горка, кусты. Это и есть прострелы.
- `decor` ни с чем не сталкивается: тополь, фонарь, мусорка, граффити.
- `height` в юнитах 3D, только для картинки.
- `kind` из списка: `panelka, garage, kiosk, shop, lada, priora, fence, wall, bench, sandbox, slide, bush, swing, poplar, lamp, trash, graffiti`.

## Формат оружия (`SHOP` в `public/weapons.js`)

Старые поля остаются: `name, emoji, price, dmg, rate, speed, range, r, count?, spread?, fx?`.
Новые, все необязательные:

- `pierce: 0..2` пробивает столько целей насквозь
- `bounce: 0..3` рикошетов от `solid`
- `lob: true` летит навесом, перелетает `low`, рвётся в точке прицела
- `ignite: {r, ms, dps}` на месте попадания остаётся огонь
- `model` рецепт 3D-модели (ниже)

Бюджет DPS 300 остаётся законом. Огонь считается в DPS пушки как `dps * ms / rate`.

## Рецепт модели (`model`)

Никакой генерации 3D. Модель собирается на клиенте из 1–6 примитивов за доли миллисекунды:

```json
{ "parts": [ { "shape": "box|cyl|sphere|cone|torus", "size": [0.1, 0.1, 0.6], "pos": [0, 0, 0], "color": "#c08552" } ],
  "projectile": "emoji|ball|arrow|disc|slipper", "trail": "none|fire|ice|smoke|sparkle" }
```

Нейросеть в кузнице отдаёт такой же рецепт, `normalize()` режет лишнее (не больше 6 частей, размеры 0.02–1.5).

## Сущности не оружие

| Сущность | Где живёт | Поля |
|---|---|---|
| Бабка (NPC) | `room.npcs` | `id, kind, x, y, hp, alive, target` |
| Бомба-тапок | `room.bomb` | `state: carried|planted|defused|boom, x, y, carrier, plantedAt, progress` |
| Огонь | `room.zones` с `kind: "fire"` | как зоны скиллов |

Snapshot отдаёт `npcs` и `bomb` дополнительно к старым полям. `meta` отдаёт `map` (id карты), клиент сам грузит `/maps/<id>.json`.

Режимы `mode`: `1v1`, `2v2` (раунды и бомба), `dm` (каждый сам за себя, возрождение).
