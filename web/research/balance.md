# Баланс двора

Расчёт оружия: один снаряд попадает в одну цель, все дробины попадают, статус не наносит дополнительного урона. DPS = `(dmg * count + ignite.dps * ignite.ms / 1000) * 1000 / rate`. TTK = `ceil(HP / damagePerShot) * rate / 1000`. Огонь в этой оценке каждый раз полностью отрабатывает и может накладываться, поэтому это верхняя оценка урона. Радиус оружия это `r` снаряда, для молотова отдельно указан радиус огня. HP у пушки нет.

## Скиллы персонажей

HP относится к персонажу. Частота у активных скиллов указана как время перезарядки. TTK рассчитан для бесконечных повторных применений одного скилла с идеальным попаданием: `ceil(HP цели / (dmg * count)) * cd / 1000`. Для одиночных эффектов это ориентир сравнения, не прогноз реального боя. `н/п` означает, что скилл не наносит прямого урона. Радиус 0 означает, что поле `r` у скилла отсутствует.

| Огонь молотова | нет | 40 DPS, максимум 120 за 3 с | 3 с | 100 | не убивает в одиночку | не убивает в одиночку |
| Лада | неразрушима | 0 | нет | укрытие по карте | н/п | н/п |

Для бабки предложена логика цели: последний ударивший, иначе ближайший в 350 px. Это пока балансная спецификация, серверную реализацию ведёт другая задача. Бомба наносит на расстоянии `d` урон `600 * (1 - d / 320)` при `d <= 320`.
