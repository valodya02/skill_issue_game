# Codex: показать карту «Спальник» (rayon.json) целиком

Цель: Саша и команда видят, как выглядит карта, не заходя в матч: план сверху с подписями и свободный облёт 3D.

## Что сделать

1. Новый файл `web/public/mapview.html` (сервер раздаёт `public/`, откроется как `http://localhost:3097/mapview.html`). Без сборщика, three берётся так же, как в `index.html` и `client3d.js` (импорт из `/vendor/...`, посмотри, как это сделано там, и повтори).
2. Слева панель с переключателями, справа два режима (кнопки «План» и «3D»):
   - **План**: canvas 2D, мир `W×H` из `/maps/rayon.json` вписан в окно. Рисовать слоями с легендой и галочками: `solid` (стены, тёмные), `low` (низкие препятствия, через них прыгают, полупрозрачные), `decor` (декор, пунктир), `spawns` (по командам, цвета `#36c5ff` и `#ff4f7b`), `sites` (точки A и B кругами радиуса `r` с буквой), `turrets` (позиция + сектор обстрела: угол `ang` в градусах, ширина `arc`, дальность 800 px), `shops` (ларёк, круг `r`), `npcs`, `audio`. У каждого объекта подпись `id`/`kind`, если есть. Сетка каждые 100 px с координатами по краям, под курсором координаты мира x, y.
   - **3D**: сцена через `buildMap(scene, map)` из `public/map3d.js` плюс `applyLook`, `sky`, `fog`, `lights` из `public/look3d.js` (те же, что в игре). Камера OrbitControls (`/vendor/...examples/jsm/controls/OrbitControls.js`, проверь, что файл есть в `node_modules/three/examples/jsm/controls/`; если `/vendor` раздаёт только `build`, добавь в `server.js` одну строку `app.use('/vendor/jsm', express.static(... 'examples', 'jsm'), { maxAge: '7d', immutable: true }))` и больше ничего в сервере не трогай). Кнопки ракурсов: «сверху», «с точки A», «с точки B», «со спавна 0», «со спавна 1», «от первого лица» (глаз 1.75 юнита, WASD + мышь). Координаты: 1 юнит = 40 px, `X = x/40 - 20`, `Z = y/40 - 11.25`.
   - Счётчик в углу: draw calls, треугольники, FPS (`renderer.info`).
3. Кнопка «Скачать PNG» сохраняет текущий вид (`canvas.toBlob`).
4. Новый скрипт `web/research/map_report.js` (Node, без зависимостей): читает `rayon.json`, печатает сводку: размер мира, сколько объектов каждого типа, площадь, закрытая `solid` и `low` в процентах, расстояния спавн → A и спавн → B по прямой для обеих команд, есть ли объекты вне мира или пересечения спавнов и точек с `solid`. Выход 0, если проблем нет, иначе 1 со списком.

## Не трогать

`rayon.json` (формат и хитбоксы), `map3d.js`, `look3d.js`, `client.js`, `client3d.js`, `move.js`. Сервер только одна строка выше, если без неё никак. Без новых npm-зависимостей. Без реальных брендов, без длинного тире.

## Проверка (вставь вывод в отчёт)

- `node web/research/check_server.js` зелёный.
