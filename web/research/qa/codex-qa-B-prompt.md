# Codex QA-B: честный игрок. Пройди всю игру и найди, где механики врут

Пишешь только в `web/research/qa/B/`. Код игры не трогай. Параллельно тестер QA-A ищет читы, это не твоя задача.

Прочитай `web/server.js`, `web/lib/*.js`, `web/research/CONTRACT.md`, `web/research/e2e_mp.js`, `web/research/roster.md`, `web/public/chars.js`, `web/public/weapons.js`, `web/public/maps/rayon.json`.

Подними сервер: `PORT=3102 node server.js` (из `web/`). Не поднимается в песочнице, значит первая строка отчёта об этом, скрипты всё равно пиши.

Скрипт `web/research/qa/B/playthrough.js [url]`: два клиента-человека (сценарий демо жюри) играют друг с другом.
1. **2v2**: два человека в разных командах плюс по боту, полный матч до `matchEnd`: каждый раунд покупка, бой, хотя бы одна закладка и один дефьюз тапка через `code`, `rematch`
2. **dm**: те же двое, до конца матча
3. **каждый из 9 персонажей** (`chars.js`) хотя бы раз: выстрел, каждый скилл `q/e/r`; скилл без эффекта в snapshot или fx = находка
4. **каждое оружие** из `weapons.js`: купить, выстрелить, проверить урон по факту падения hp против заявленного (допуск 10%), перезарядку
5. **гранаты** кофе и дым, турель (перегрев за ~3 с), прыжок через лавку (`low`) и упор в `solid`
6. **инварианты на каждом snapshot**: hp в `[0, max]`, деньги ≥ 0, никто не внутри `solid`, координаты в поле, ровно одна фаза, таймер не растёт, мёртвые не стреляют, счёт только растёт

Печатай `PASS / FAIL / SKIP` на пункт. Каждый FAIL в `web/research/qa/B/BUGS.md`: `тяжесть | шаги | ожидание | факт | где в server.js скорее всего`. Фиксы не применяй.

Плюс `web/research/qa/B/BALANCE.md`: время до убийства (TTK) каждого оружия по полному hp, сравнение с бюджетом 300 DPS, кто сломан.

## Готово, когда
`node --check` проходит, в отчёте число пунктов, FAIL, прогонял ли живьём, сколько длился прогон.
