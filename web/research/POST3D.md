# Подключение картинки 3D

В `game3d.js` после создания `renderer`, `scene`, `camera` подключи модуль и замени основной вызов отрисовки. Три строки интеграции:

```js
import { createPost } from './post3d.js';
const post = createPost(renderer, scene, camera, { outline: true });
post.render(dt); // dt в секундах, вместо renderer.render(scene, camera)
```

На resize вызывай `post.resize(w, h)` с размерами буфера в пикселях. При завершении сцены вызывай `post.dispose()`. При создании карты сохрани `scene.userData.map = map` для света у фонарей, вызови `applyLook(scene)`, `sky(scene)`, `fog(scene, 'autumn')`, `lights(scene, 'autumn')` из `look3d.js`. Материалы, возвращённые `applyLook`, стоит освобождать вместе со сценой. Небо добавляй после `applyLook` либо оставляй его флаг `noToon`.

| Событие сервера или состояние | Вызов |
|---|---|
| Полученный урон своему персонажу | `post.kick('hit', 1)` |
| FX `coffee` рядом с игроком | `post.kick('coffee', 1)` |
| Игрок в зоне `smoke` | `post.kick('smoke', 1)` |
| Статус `slowmo` у игрока | `post.kick('slowmo', 1)` |
| FX `boom` рядом с игроком | `post.kick('boom', 1)` |
| Свой персонаж погиб | `post.kick('death', 1)` |

`amount` лежит в диапазоне 0..1. Повторный `kick` обновляет время эффекта. Неизвестное имя игнорируется.

| Фаза | Пресет |
|---|---|
| Лобби | `post.setPreset('vhs')` |
| Бой | `post.setPreset('autumn')` |
| Конец матча | `post.setPreset('night')` |

`off` рисует сцену напрямую. Включённый пост использует один рендер сцены в texture и один полноэкранный треугольник. Контур вычисляется в том же полноэкранном шейдере по depth texture, отдельного прохода нет. `outline: false` выключает выборки глубины. Если WebGL2 отсутствует или depth target не создаётся, контур выключается автоматически. Нормаль для контура оценивается из соседних значений глубины, отдельной texture нормалей нет.

Оценка бюджета для Vega 8 в 1080p: примерно 1,0-1,8 мс у полноэкранного шейдера с контуром, ниже без контура. Это гипотеза до измерения в браузере, предел 1,5 мс не подтверждён. В `demo3d.html` F3 показывает GPU время только пост прохода, если доступен `EXT_disjoint_timer_query_webgl2`, а также FPS и draw calls.
