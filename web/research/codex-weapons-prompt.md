# Задача для Codex: оружие, урон всех сущностей, модели

Сначала прочитай `web/research/CONTRACT.md`. Формат и границы файлов оттуда главнее этого текста.
Пишешь только `web/public/weapons.js`, `web/forge.js`, `web/public/parts3d.js`, `web/research/balance.md`, `web/research/check_balance.js`.
Если готов `web/research/weapons.json` (ресёрч механик из других игр), бери идеи оттуда.

## Контекст

Шутер 2 на 2 в духе CS на карте «спальный район». Игрок 28 px радиус, у персонажей 700–1400 HP, раунд 100 секунд, экономика в `ECON`.
Сейчас в `SHOP` 6 пушек и бюджет `MAX_DPS = 300`. Цель: время до убийства (TTK) танка в 1400 HP не меньше 4,5 секунды из любой пушки (потолок 300 DPS даёт 4,7) и около 15 секунд из бесплатного пистолета (сейчас 34 урона раз в 380 мс), чтобы закупка решала.

## 1. Арсенал двора (в `SHOP`)

Оставь существующие, добавь не меньше 8 новых, среди них обязательно:

- **Лук со стрелами**: медленный, дальний, `pierce: 1`, стрела модель `arrow`
- **Камни**: дешёвые (200–400$), навес `lob: true`, перелетают лавки и песочницу
- **Тапок-бумеранг**: `bounce: 2` от стен гаражей
- **Зажигалка (молотов)**: только в ларьке `kb`, `lob: true`, `ignite`
- **Семечки**: пушка бабки, в магазине нет (id `babka_seeds`)

Для каждой: `price, dmg, rate, speed, range, r`, по надобности `count, spread, fx, pierce, bounce, lob, ignite`, плюс `model` по рецепту из контракта и `lore` одной угарной фразой.

## 2. Урон всех сущностей (`research/balance.md`)

Таблица: сущность, HP, урон, частота, радиус, TTK по танку 1400 HP и по лёгкому 700 HP. Сущности:
все пушки, скиллы из `public/chars.js` (их только считай, файл не правь), бабка (HP, урон семечек, радиус агра), бомба-тапок (радиус и урон взрыва), огонь молотова, «Лада» (неразрушимая, только укрытие).

Предложение по умолчанию, можешь спорить с цифрами в отчёте: бабка 250 HP, семечки 12 урона раз в 0,8 с на 350 px, бьёт того, кто ударил её последним, иначе ближайшего; бомба радиус 320, урон 600 в центре, линейно до 0 на краю; огонь 3 с, 40 DPS.

## 3. `normalize()` для новых полей

Новые поля режутся в лимиты (`pierce 0..2`, `bounce 0..3`, `ignite.r 30..120`, `ignite.ms 500..4000`, `ignite.dps 10..60`). Огонь входит в DPS-бюджет по формуле из контракта.
`model`: не больше 6 частей, `shape` только из списка, размеры 0.02–1.5, цвет только `#rrggbb`; кривой рецепт меняется на рецепт по `emoji`, а не роняет игру.

## 4. Кузница (`forge.js`)

Промпт `SYSTEM` теперь просит и новые поля, и `model`. Локальный фолбэк тоже собирает рецепт из слов промпта (тапок → `slipper`, огонь → `trail: fire` и т.д.).
Ответ модели должен влезать примерно в 300 токенов, чтобы маленькая локальная модель отвечала за 1–2 с.

## 5. `parts3d.js`: ES-модуль на Three.js 0.180

```js
import * as THREE from '/vendor/three.module.js';
export function buildWeapon(model) {}      // Group для руки игрока
export function buildProjectile(model) {}  // меш снаряда, общий на все одинаковые снаряды
export function trailFx(scene, kind) {}    // частицы на Points, без новых мешей на каждую частицу
```

Оптимизация: кэш геометрий и материалов по ключу рецепта, снаряды одного типа через `InstancedMesh`, частицы только `Points` с пулом не больше 500 точек.
