# Skill Issue Arena — описание проекта и прогресс

Дата обновления: 2026-10-25

## Описание проекта

`Skill Issue Arena` — простая многопользовательская браузерная игра от первого лица.
Игроки бегают по блочной арене в стиле Minecraft, прыгают, ускоряются и собирают монеты.
Раунд длится 60 секунд, побеждает игрок с наибольшим числом монет.

Стек:

- Клиент: Three.js 0.180.0, нативный JavaScript (ES-модули), HTML, CSS.
- Сервер: Node.js, `http`, `ws` 8.22.0.
- Three.js отдаётся локально из `node_modules`, внешний CDN не нужен.
- Сервер авторитетен: позиции, прыжки, скорость, сбор монет, счёт и раунды считает он.

В репозитории также сохранён пустой каркас Unity-проекта (`Assets/`) из первого этапа.

## Как запустить

```bash
cd /home/nexar/Game_issue/webgame
npm install
npm start
```

Открыть: http://localhost:3000

Важно:

- Открывать через сервер, а не через `file://`.
- После изменения `server.js` сервер нужно перезапустить.
- Если порт занят: `kill $(lsof -t -i:3000)`.
- Порт задаётся переменной `PORT`, длительность раунда — `ROUND_SECONDS`.

Управление:

- `WASD` / стрелки — движение.
- `Shift` — ускорение.
- `Space` — прыжок.
- Клик по полю — захват мыши, обзор мышью.
- `Esc` — освободить курсор.

## Известные ограничения

- Деревья, камни и декор не имеют коллизий — игрок проходит сквозь них.
- Базука пока только визуальная: стрельбы, ракет, урона и взрывов нет.
- Другие игроки отображаются кубами, без анимации конечностей.
- Одна монета на всю арену; нет разных типов бонусов.
- Нет мобильного управления и геймпада.
- Нет сохранения рекордов, аккаунтов и постоянного лидерборда.
- Нет автоматизированных тестов в репозитории (проверки выполнялись ad-hoc).
- Конфиг сцены влияет только на клиент; границы арены заданы на сервере (`ARENA_HALF = 20`).
- Для изменения серверной логики нужен перезапуск сервера.
- Текущие изменения не закоммичены: `README.md`, `server.js`, `game.js`, `index.html`,
  новый `scene-config.js`.

## Краткий протокол WebSocket

Клиент → сервер:

- `{ type: 'join', name }`
- `{ type: 'input', x, z, sprint }`
- `{ type: 'jump' }`

Сервер → клиент:

- `{ type: 'welcome', id, world }`
- `{ type: 'state', phase, timeLeft, winner, coin, players }`

В `players` передаются `id`, `name`, `color`, `x`, `y`, `z`, `score`.
