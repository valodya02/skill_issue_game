# 🔥 BRAINROT-STRIKE

> Мультиплеерный шутер от первого лица прямо в браузере. Бегаешь, стреляешь пельменями, а в ухе тебе орёт стример Вася «Гигачад» Бомбастиков и даёт советы. Половина гениальна, половина ведёт на смерть. Какая именно, узнаешь по ходу дела.
---

## 🎮 Что это

Арена-шутер на 2-8 игроков. Кидаешь друзьям ссылку, все заходят в браузере, ничего ставить не надо. Играть можно с компьютера и с ноутбука, на вечеринке, в дискорде или просто когда скучно.

## ✨ Фичи

- 🌐 **Играется в браузере**, заходишь по ссылке за пару секунд
- 👥 **Мультиплеер** на несколько игроков в одной комнате
- 🎧 **Вася-помощник**: субтитры и голос через встроенный синтез речи, советы привязаны к происходящему
- 📊 **Шкала доверия Васе**: слушаешься и выживаешь, получаешь бонусы («ДОНАТ ПРИЛЕТЕЛ» = аптечка). Игнорируешь, и он обижается
- 💬 **Чат стрима** справа, который спорит с Васей и спамит подсказками
- 🔫 **Мемное оружие**: тапок с автонаведением, пельменная пушка, «Аура-бластер»
- 🏟️ **Абсурдные арены**: заброшенный ТЦ, гигантская кухня, парковка в аду
- 🏆 Счётчик убийств и таблица результатов

## 🚀 Быстрый старт

Нужен [Node.js](https://nodejs.org/) 18 или новее.

```bash
# 1. Клонируем репозиторий
git clone https://github.com/ТВОЙ-НИК/chaos-arena.git
cd chaos-arena

# 2. Ставим зависимости
npm install

# 3. Запускаем сервер и клиент
npm run dev
```

Открой в браузере `http://localhost:3000`, и ты в игре.

## 👯 Как играть с друзьями

**Вариант 1. В одной сети (Wi-Fi).** Узнай свой локальный IP и дай друзьям адрес вида `http://192.168.x.x:3000`.

**Вариант 2. Через интернет без хостинга.** Пробрось локальный сервер наружу:

```bash
cloudflared tunnel --url http://localhost:3000
# или
ngrok http 3000
```

Отправь друзьям полученную ссылку, и всё.

**Вариант 3. Выложить на хостинг.** Подойдут Render, Fly.io или Railway. Сервер обычный Node.js, настроек почти никаких.

## 🕹️ Управление

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | Бегать |
| Мышь | Крутить камеру |
| ЛКМ | Стрелять |
| `Пробел` | Прыжок |
| `R` | Перезарядка |
| `1` `2` `3` | Выбрать оружие |
| `Tab` | Таблица результатов |
| `M` | Заткнуть Васю на 10 секунд (стоит монетку) |

## 🛠️ Технологии

- **[Three.js](https://threejs.org/)**: 3D-графика и камера от первого лица
- **[Node.js](https://nodejs.org/)** + **[Colyseus](https://colyseus.io/)**: сервер, комнаты и синхронизация состояния
- **WebSocket**: связь клиента с сервером
- **Web Speech API**: озвучка Васи прямо в браузере
- **glTF / GLB**: формат 3D-моделей

## 🎨 Как добавить свои модели

1. Скачай или сделай модель в формате **`.glb`**
2. Положи её в `client/public/models/`
3. Подключи в коде:

```js
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

new GLTFLoader().load('/models/my-weapon.glb', (gltf) => {
  scene.add(gltf.scene);
});
```

Бесплатные низкополигональные модели есть на [Kenney](https://kenney.nl/), [Quaternius](https://quaternius.com/) и [Poly Pizza](https://poly.pizza/). Лицензии проверяй.
